Excel Sales Performance Dashboard

An Excel-based data analysis project that transforms fictional sales transaction data into an interactive visual dashboard for monitoring business performance.

Features
- KPI Metrics: Total revenue, gross profit, units sold, and transaction count.
- Product Analysis: Compare revenue and gross profit across different products.
- Sales Channel Analysis: Evaluate revenue generated through Instagram, WhatsApp, TikTok, and walk-in sales.
- Data Analysis: Excel formulas, SUMIF functions, summary tables, and charts.
- Data Organization: Structured transaction records containing product, region, sales channel, units sold, unit price, and unit cost.

Tools Used
- Microsoft Excel
- Excel formulas and functions
- Data visualization and dashboard design

### Objective
To demonstrate how Excel can be used to organize sales data, track key performance indicators, identify top-performing products and sales channels, and support data-driven business decisions.
